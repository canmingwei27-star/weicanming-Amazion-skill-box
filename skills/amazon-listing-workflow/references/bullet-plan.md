# 五点规划与生成

必须按“先分主题 → 分配事实、竞品依据和词根 → 再写成稿 → 全局去重”执行。只要求修改Skill时只更新规则和必要示例，不擅自重写整套Listing。要求生成时先展示简短五点主题表，资料齐全即可接着写，不额外等待用户批准。

## 一、先准备可用主题与词根

读取本品确认资料、竞品卖点分析、原关键词、词根的“词语/关键词性/属性”、品牌及违规词规则。

同时建立两类候选：
- 竞品主题：规格、操作、材质/结构、场景、人群等。记录竞品ID、原点序号、原文片段、本品可采用部分；不能仅按高频或照抄竞品顺序。
- 词根主题：按属性整理核心产品、规格、功能、用途、场景、人群。场景词根既可用于埋词，也可形成独立卖点；不能只在第五点集中列举。

用户已标注或明确允许采用的场景、用途词，结合本品常规用途直接规划，不要求逐个再次确认，也不因产品信息表只写了简短场景就全部搁置。保留原相关性等级。明确不符的颜色/数量/规格、其他品牌和禁词仍排除；场景词不能延伸为资料没有的防水、耐热、承重等性能承诺。竞品性能不作为本品事实。

精准级别先后为绝对精准、相对精准、一般相关、泛相关；事实适用且确有补充价值的未收录词再考虑。不相关词不使用，未知等级单列。原关键词同级才比较原搜索量，词根不虚构搜索量。

## 二、先形成五行提纲

每行明确：点位、唯一核心主题、买家问题、主要主张、事实ID、竞品依据、重点关键词/词根、场景埋词位置、该点不再展开的内容。保存为bullet_outline，不能成稿后倒填提纲。

| 点位 | 软长度目标 | 内容职责 |
|---|---|---|
| 1 | 约150字符 | 包装与规格：产品是什么、数量、总量、必要尺寸。规格类内容集中于此 |
| 2 | 约150字符 | 最主要痛点及已证实解决方式，让买家看到实际利益 |
| 3 | 约400字符 | 从竞品主题和词根属性中选一个有依据、未被前两点占用的主题；可为具体场景 |
| 4 | 约400字符 | 选择与前面三点不同的主题；可为另一具体场景、操作或材料结构 |
| 5 | 约400字符 | 尚未覆盖的用途、人群、使用方式或其他购买理由，结合适用场景词根 |

第三至五点按产品实际资料选题，不固定写成“材质、使用、场景”，也不把两点都写成尺寸选择。所有点之间都检查重复，不仅检查第三与第四点。

每个主要主张只有一个归属点。珠径、各卷长度、尺寸选择、总长度、包装数量属于同一“规格”主题组，不能换一个小标题就算新卖点。第一点容纳不下的完整尺寸表、单位换算移到长描述、规格字段或图片；不因此另开“每卷长度”一点。

核心产品名或关键词可以按需要重复；主体利益、参数清单和使用说明不能重复。其他点确需引用某参数时，只作简短辅助依据，说明新增决策价值，不再次列全套规格。两个不同场景可以分成两点，但必须分别讲具体用途与不同使用语境，不能都复制“适用婚礼、圣诞、DIY”清单。

内容不足时缩短对应点并说明缺口，不为了约400字符反复讲尺寸或虚构功能。主题不足五个时保留已支持部分，不能把同一个主题拆成两个凑数。

## 三、按主题分配词根，再写正文

对每点建立埋词计划：原词/原短语、root_id或keyword_id、属性、原相关性、计划嵌入的句子位置和用途。场景词应分配到解释该场景的点，不平均摊词，也不只允许最后一点出现。

例如原词库包含wedding、bouquet、table、christmas、tree、crafts、diy时，可以将婚礼花束/桌面布置和圣诞树装饰作为不同主题，DIY点承担手工操作或人群；是否采用以本品用途、用户标注与禁用规则为准。不得为套用示例虚构原表词条。

每点沿“明确特点/场景 → 如何使用或解决什么问题 → 买家利益”展开。先讲清主题，再把分配好的词根融入；不把第五点写成关键词串。完整精准短语在语法可行时优先保留；需要改写时区分原短语命中、词形、重组/分散覆盖，不冒充精确命中。

主副标题的严格“全部来自词根库”约束不自动扩展到五点。五点可以用本品事实和必要语法表达，但关键词选择遵循词库，不能用自行想出的卖点替代已分配的精准词与场景词。

## 四、竞品参考与事实

第3、4点的竞品参考优先级保留为强对标竞品＞对标竞品＞竞品＞空白，不自行重标。可合并多家竞品的同类主题，也可拆分一个竞品混在同一点的不同主题，再按本品提纲重新归位。

保留“参考来源 → 可借鉴主题/结构 → 本品事实/用户场景授权 → 目标点位”的映射。竞品缺失可依据事实与词根先写，标明未完成竞品参考；不能编造竞品趋势。

## 五、生成后的全局复查

先逐点概括成一句中文主旨，再并排检查五句是否独立：
- 尺寸/长度主题是否跨点重复，是否只是换小标题重复事实？
- 第3、4点是否真正新增购买信息，是否沿用了竞品规格而非本品事实？
- 场景词是否在适合的点位实际出现，并解释了用途，而非遗漏或机械列举？
- 正文是否偏离提纲，是否新加了其他点已经负责的主要主张？
- 精准词的计划与实际覆盖是否一致，未用词是否有具体原因？

主题重复时先合并或重新分配提纲，再修改相关正文；不能只更换词汇。修改后复查长描述、补充QA与ST的衔接。

每点实际计数包含空格、标点和内部小标题，不含外部编号。150/150/400/400/400均为软目标，不凑字数。正文末尾不得加标点；句中可正常使用。实际平台限制另核对，不将软目标当平台通用上限。

## 输出与记录

先交五点主题表，再按同一顺序交实际文案；规划请求只交提纲。draft.json保存bullet_outline和bullets的point_id/topic_id/claim_ids对应关系，来源与词根映射留在内部报告，不混入商品正文。

运行scripts/check_copy.py，检查提纲存在、点位对应、主要主题与主张重复、数量、字符和结尾标点。脚本只能检查声明的topic_id/claim_id，不能识别所有语义重复；必须完成上述人工全局复查。不得用五个不同编号包装同一个主题。
