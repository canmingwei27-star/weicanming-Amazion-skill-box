# 九图策划与变体契约

## 固定顺序

| 图号 | 类型 | 必须落实的内容 |
|---|---|---|
| 1 | 主图 | 当前MSKU实际售卖主体及数量；呈现产品识别与外观，不把多颜色家族合拍冒充单色包装 |
| 2 | 尺寸图 | 产品实际尺寸、售卖长度/数量、必要局部结构比例；明确测量部位和单位，不使用包装外尺寸代替产品尺寸 |
| 3 | 单一场景图1 | 选择一个有事实/用户用途授权的具体场景，说明如何摆放与使用，只展现一个场景 |
| 4 | 单一场景图2 | 与图3不同的单一场景及购买理由，不用同场景换角度凑数 |
| 5 | 细节图 | 聚焦能证实的材质、结构、纹理、连接或工艺细节；不要以放大图捏造微观结构或性能 |
| 6 | 多应用/多场景图 | 默认四宫格，逐格列场景、构图、道具与短文案；四个应用有依据，不能为凑格虚构功能 |
| 7 | 合拍图 | 多颜色优先对颜色合拍，色名和实际MSKU对应；多尺寸可比较尺寸。注明可选变体非整套包含，除非确为混装套装 |
| 8 | 使用说明图 | 根据已确认结构和用途组织实际步骤、工具、起止状态及必要限制；未知胶种、缝制、耐热等不当作已验证说明 |
| 9 | SKU图 | 单独突出该MSKU最能区分的花型、局部结构、颜色或尺寸差异。允许紧凑裁切/放大，如小花图案只放大小花，无需强行展示整件；让买家清楚所选版本 |

图5回答质量/结构细节，图9回答“我选的是哪个版本”，两者不要交相同画面。图7是家族合拍，图9通常逐MSKU输出具体裁切方案；所有MSKU都需有对应关系。单变体没有颜色/尺寸家族时，图7可拍实际包装内组合或同一产品不同视角的组合展示，明确非额外件数，不虚构变体。

## 变体适配

每图记录scope（shared/per_variant/per_family）、applicable_mskus、changing_elements、fact_ids、copy_sources。颜色变化影响所有能看见产品颜色的画面，即使构图/文字共用也需换成正确素材；尺寸变化影响比例、标注、用量、包装数量与使用步骤。价格和物流重量默认不做上图卖点。

不要固定宣称图1/2/9都可共用，也不机械为每色写完全重复的九份方案。先提供父体九图母版，随后列每张需要换哪些颜色、尺寸、局部特写、文字及对应MSKU。合拍可共享构图；差异特征不足时明确待补真实参考图，不凭颜色名字推断光泽、纹理或印花。

## 数据、语言与交付

image-plan.json包含parent_sku、source_listing_version、source_variant_version、language、images（严格1–9）、variant_adaptation、open_questions、platform_checks和output_html。images每项含image_id、type、objective、buyer_question、fact_ids、copy_sources、composition、product_view、props、assets_needed、overlay_text、overlay_translation_zh、applicable_mskus、changing_elements、review_notes。

上图英文短句与中文一一对应，数量/单位及事实不变。中文拍摄指令无需重复译成英文；客户可见文字、图内标签和关键规格须有双语对照。图9可无文字或仅给属性标签，不把内部MSKU编号强制写到图上。合拍图的“可选颜色”标签不代表套装含所有颜色。

验收九个编号、固定类型、两张单场景彼此不同、四宫格逐格说明、图8步骤有依据、图9每个MSKU辨识明确、事实引用、双语文字及独立文件交付。保留未知资料，不能用渲染图片去证明材质和尺寸。
