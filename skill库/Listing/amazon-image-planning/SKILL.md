# 产品图片策划

本技能只策划图片，不调用图像生成、不伪造产品照片、不修改或重新排版现有Listing页面。完整Listing项目在文案生成后衔接本技能；仅修改单个字段的任务不扩大为整套图片策划，除非用户要求。

读取最新已确认本品事实、当前实际标题、五点、长描述、QA状态、已有真实产品图片和variants.json。已有文案用于安排信息重点，不能把无来源的旧文案或未确认QA当成事实；竞品仅参考结构，不移植功能、尺寸或认证。新变体表属于新产品时先区分父体，不能继承珍珠串等旧项目事实。

按 [九图模板](assets/nine-image-plan-template.md) 固定输出图1–9，使用 [策划与变体规则](references/planning-contract.md)。用户最新明确要求为9张，不再按7或8张交付。

输出以中文文本分条排列，每张图都写具体内容：核心目的、对应购买疑问、事实及文案依据、画面主体、构图/拍摄与裁切、需要的素材、目标语言上图文案及中文翻译、适用MSKU及变化、缺失项与验收要点。不能只交九个名称，不能把所有内容拼成生成模型提示词。没有上图文字时明确“无”，不硬凑英文口号。

交付为独立的UTF-8双语HTML文件，例如Image-Plan-<父体SKU>-vN.html，另保存image-plan.json。不得放在Listing页面底部、同一页面折叠区、iframe或同一文件的切换面板；提供独立文件链接，展示时打开独立标签页。不要为了图片策划重新排版Listing。一个父体一份方案，可在该方案中展示MSKU适配表，明确各图共享或单独制作。

主图按当前站点/类目官方要求核对后规划，保存来源与日期；无法验证时注明规则未核验，不声称全部符合。九图属于本项目策划顺序，不保证类目支持上传9张或第9张就是后台指定槽位。商品不随售的配件、其他颜色或其他长度不能被主图暗示为包装内容。

未确认规格、步骤或特性写进缺口，不编造；可先完成不依赖缺口的图。用户仅要求创建/修改技能与模板时，交付规则及模板，不擅自给当前产品生成完整图稿或替换现有Listing。
