# 变体与商品资料区

本区替换原来的“选择颜色版本”，不并排保留两个互相独立的选择区。页面其余Listing结构可沿用，不为增加变体重新设计整页。

## 控件与状态

- 多父体先显示产品/父体SKU选择；单父体作为信息显示。
- 属性轴从variants.json读取。仅颜色可变则显示颜色选项；颜色及长度可变则分别显示两轴；固定1码等只作固定规格显示。
- 联动选项只允许实际存在的组合；禁用或不展示无对应MSKU的组合。属性不足以唯一定位MSKU时显示MSKU选择或冲突提示，不猜测。
- 用户切换后同一次渲染更新全部相关内容；“复制当前MSKU全部英文”始终从选中variant_id数据读取，保持语言显示模式，不混入上一变体。
- 缺失显示“未提供”，冲突显示“待核实”。允许查看有问题的行及原始值；依赖冲突事实的文案不能伪装成已通过可发布稿。

## 每个MSKU展示的资料

品牌、分类、父体SKU、MSKU、属性名称及值、实际规格原文、售价和币种、商品净重/商品重量（明确类型及单位）、包装长×宽×高（带单位）、包装重量（带单位）。即使净重未提供也保留该字段提示，不用包装重量填补。价格仅显示该行提供值，不自动作承诺、折扣或促销卖点。

英文文案和中文翻译分开；后台识别码原样显示，不翻译MSKU。可提供“复制当前MSKU资料”与“复制当前MSKU英文文案”两个不同动作，不能把物流参数一起复制进标题或ST。

## 测试

每个有效MSKU核对属性→身份→文案→中文→价格→规格重量→计数→复制内容一致。覆盖同色不同尺寸、同尺寸不同颜色、组合缺失、重复MSKU、冲突、缺失重量及多个父体。检查窄屏溢出、键盘/按钮可操作性及语言切换保留。固定属性不制造重复选择器。

示例修正：用户已将Red/Black/White三个-5Y更正为-1Y；如果8行中重复行所有字段一致，应显示5个唯一子体（Red、Black、White、Pink、Champagne），共同1码，并保留8个来源行。此示例不是珠串项目的SKU或重量数据。
