# 标题规则依据

采用用户已确认的写作要求与本品资料。此前标题公告引用及其核查日期说明已取消，不作为本流程的标题依据，也不再写入HTML“数据与规则来源”。不要从旧稿或历史审计恢复该引用。

主标题顺序为品牌→数量→总长度→颜色→精准关键词→补充词根，目标及上限75字符（含空格）。副标题采用词根堆积，严格大于110且小于125字符，即111–124字符，禁止标点和符号，使用单空格。仅主标题四个固定前缀字段可来自产品事实，其余标题文字和全部副标题取自词根库，词根在两段合计最多两次。

以上数字与写法标注为用户规则，不再声称由已取消的公告验证。实际字段映射未知时保留未知，不将副标题自动认定为后台提供的字段。具体执行见[标题规划](title-plan.md)。
