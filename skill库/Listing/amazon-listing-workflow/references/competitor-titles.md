# 标题竞品分析

只负责竞品“商品标题”字段的分析，输出本品标题写作参考。五点竞品分析由内部模块处理；两者可分别执行。

## 输入

优先使用 `data-intake.md` 接收后的 `competitors`、`sources`、`product_data / facts`、`project`、`brand_rules`、`forbidden_terms` 和未决问题。只有原表时，按包内 [资料接收规则](data-intake.md) 整理。

竞品库第一张表（名称示例 `US`）读取“竞品类型”“ASIN”“商品标题”；第二张表（示例 `Brands`）读取“品牌”。表名和顺序仅为线索，须核对字段。不要求提供产品卖点才能执行本模块。

产品信息表提供本品品牌、功能、规格、适用对象和限制等事实。项目资料提供目标站点、类目、语言及标题要求。缺失时可以先拆解竞品结构，但不能宣称本品内容或规则已经验证。

## 筛选与参考顺序

强对标竞品 ＞ 对标竞品 ＞ 竞品 ＞ 空白。沿用原标签，未知或冲突标签单列核对；不擅自重标等级，不设置未经用户规定的分数权重。

优先参考高等级竞品，低等级可补充角度。未指定数量或等级范围时，不自行只取前几条或删除低等级记录。说明实际分析范围、缺失项和排除理由。

结合产品用途、规格和变体判断可比性；不适用于本品的内容明确标注。标题缺失不表示竞品缺少某项功能。

沿用接收阶段的站点、ASIN、变体及来源标识处理重复。同一竞品的重复行和重复采样不重复计入产品数，版本冲突不得静默合并。

## 标题拆解

保留完整标题原文与来源，分别分析：

| 分析项 | 要求 |
| --- | --- |
| 信息构成 | 实际出现的品牌、核心产品名称、功能、规格/尺寸、数量、材料、对象或场景；不补齐缺失成分 |
| 排列顺序 | 核心产品名称的位置、前部重点、特点与规格的先后关系 |
| 表达结构 | 词组连接、标点、重复词、冗余和阅读自然度 |
| 关键词观察 | 原文出现的产品词、功能词、场景词及位置 |
| 购买信息 | 标题实际回应的识别、规格、数量、适配等问题及其依据 |
| 可参考与问题 | 可借鉴的信息组织、无本品依据的主张、其他品牌和已知禁用表达 |

没有关键词库依据时，不将竞品用词称为高搜索量词、精准词或已验证有效词。词库的相关性、搜索量筛选和最终埋词由后续关键词规划负责。

购买疑问若从标题推导，标为“潜在购买疑问（分析推断）”，不能称为真实买家反馈或已验证痛点。没有标题证据时不强行生成问题。

可统计信息构成和结构的出现频次，使用实际纳入且有可读标题的独立竞品作为分母，展示等级分布并说明缺失、排除情况。重复词的词频与采用该结构的产品数分别统计。出现频繁或在售不证明符合要求，也不证明转化更好。

## 对照本品与标题要求

每项拟迁移的信息关联产品信息表中的事实 ID，区分：

- 可参考：本品事实支持，未发现与已知规则冲突，可进入标题内容规划。
- 待确认：本品事实、变体、品牌或适用规则不明确，列具体缺口。
- 不采用：与本品不符、属于其他品牌或违反已知要求，说明原因。
- 仅参考结构：借鉴信息顺序或组织方式，不迁移竞品事实。

品牌只允许当前本品品牌，其他品牌进入排除名单，不能因某竞品未被选中就缩减 Brands 名单。品牌别名需要资料或用户确认。品牌不明时，相应检查保持未完成。

用户违规词库中的词语不得进入本品可用措辞。原始竞品标题可以作为内部证据保留命中内容，但必须与写作建议分开。未提供词库时明确检查未完成。

标题参考须满足项目已确认的站点、类目、长度、格式、品牌与事实要求。缺少规则时不能直接沿用竞品长度、符号或促销写法，也不能硬编码全站通用限制。

需要核实当前平台规则时，查阅适用的亚马逊官方来源，记录规则内容、来源、适用范围和核实日期。用户偏好与平台要求分别记录；发现冲突时说明，不把冲突内容标为可直接采用。无法核实的规则保留未验证状态。

竞品事实不能补成本品事实；本品的限制条件必须保留。不因竞品没有写某特点就宣称本品独有或更好。

## 标题写作交接

基于本次样本和本品事实，交付建议的信息构成与排列顺序，并说明取舍理由、参考来源、事实依据和未决规则。

本品结构遵循 [标题规划](title-plan.md) 的固定顺序：品牌→数量→总长度→颜色→精准关键词→库内补充词根。竞品的信息顺序与性能表达不能覆盖这一顺序，也不能替代主副标题的词根来源约束。

交付待关键词规划验证的候选词组，明确它们仅来自竞品观察。最终关键词选择、标题撰写和成稿校验由后续模块完成。本阶段不直接生成最终标题。

## 输出

输出一份标题竞品分析报告：分析范围及等级分布、逐条标题拆解、共性结构、关键词观察、本品适配矩阵、标题要求核对状态、推荐信息顺序、排除项和信息缺口。

可复用结论至少记录 insight_id、competitor_ids、source_refs、evidence、observation、inference、fact_ids、adoption_status、reason，target_field 固定为 title。规则记录附来源和适用范围；频次结论附产品数、分母和等级分布；缺失值明确为空，不补造 ID。

分析默认使用用户当前语言，原文证据保留来源语言。中间数据沿用 `work/amazon-listing/<project-id>/`，交付文件存当前工作区 `outputs/`。资料更新后复核受影响结论。

交付前检查来源可追溯、重复未放大统计、竞品用词未冒充关键词研究结论、本品建议有事实支持、品牌禁词及规则的未完成项明确。本模块不声称已完成成稿合规复查。
