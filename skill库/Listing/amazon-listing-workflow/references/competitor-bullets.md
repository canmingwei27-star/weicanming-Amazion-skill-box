# 五点竞品分析

只负责竞品“产品卖点”字段的分析，输出本品五点写作参考。标题竞品分析由内部模块处理；两者可分别执行。

## 输入

优先使用 `data-intake.md` 接收后的 `competitors`、`sources`、`product_data / facts`、`project`、`brand_rules`、`forbidden_terms` 和未决问题。只有原表时，按包内 [资料接收规则](data-intake.md) 整理。

竞品库第一张表（名称示例 `US`）读取“竞品类型”“ASIN”“产品卖点”。表名和顺序只是线索，须核对实际字段。不要求提供商品标题才能执行本模块。

产品信息表是本品事实依据。Brands 表及违规词库用于标记不可迁移到本品文案的表达。资料未提供时明确相应检查未完成，不阻塞独立的竞品原文拆解。

## 筛选与参考顺序

强对标竞品 ＞ 对标竞品 ＞ 竞品 ＞ 空白。沿用原标签，未知或冲突标签单列核对；不擅自重标等级，不设置未经用户规定的分数权重。

优先参考高等级竞品，低等级可补充角度。未指定数量或等级范围时，不自行只取前几条或删除低等级记录。记录分析范围、缺失项与排除理由。

结合产品用途、规格及变体说明可比性；明显不可比的记录可不纳入本品参考建议，但保留原标签与理由。卖点缺失不表示该产品没有某项功能。

沿用接收阶段的站点、ASIN、变体及来源标识处理重复。相同竞品的重复行和重复采样不重复计入产品数，版本冲突不得静默合并。

## 卖点拆解

保留“产品卖点”完整原文、段落和顺序。一个单元格含多点时只按明确分隔拆开，不假设原文恰好有五点。

每个独立卖点提取：

| 分析项 | 要求 |
| --- | --- |
| 来源 | 竞品 ID、ASIN、竞品类型、文件、工作表、行号、原点序号 |
| 原文依据 | 可支持结论的原文片段，完整原文仍保留在来源记录 |
| 主题与主张 | 实际功能、材料、规格、场景、操作、限制或承诺；标明属于竞品自述 |
| 用户利益 | 原文明示的利益与分析推断分开记录 |
| 表达结构 | 实际采用的小标题、特点、利益、场景、证据或限制及其顺序 |
| 表达方式 | 句式、语气、信息密度、重复强调和规格位置 |
| 潜在购买疑问 | 可能回应的选购或使用问题、对应证据及推断性质 |

按含义归类卖点，但不混淆不同规格、功能或适用条件。统计每个主题覆盖的独立竞品数和等级分布；同一竞品重复提及只计一个产品。若另列提及次数，明确其与产品数不同。

频次分母使用实际纳入且有可读卖点的独立竞品，说明缺失与排除数量。高频仅代表本次竞品文案的共同关注点，不能证明销量、转化率或消费者偏好。

## 购买疑问与事实映射

根据原文推导适配、尺寸、包装内容、使用方式或限制等疑问，必须标为“潜在购买疑问（分析推断）”，不能称为真实评价、常见投诉或已验证痛点。不为凑数量生成无证据问题，不自动扩展为最终 FAQ。

逐项对照本品信息表，将主题、利益及疑问关联到本品事实 ID：

- 可参考：本品事实支持，未发现已知品牌或禁词冲突，可交写作环节重新组织。
- 待确认：事实缺失、冲突或适用变体不明，列明具体需要补充的信息。
- 不采用：与本品不符或违反已知要求，说明原因。
- 仅参考结构：只参考信息组织，不迁移竞品的事实或承诺。

竞品信息不能补成本品事实。保留本品规格、变体及限制条件，不把局部功能扩大到全部型号。不因竞品未提及某特点就称本品独有或更好。

## 五点内容规划

结合高等级竞品主题、本品事实和词根属性，先交可追溯主题池，再交五行提纲。每点明确一个核心主题、买家问题、主要主张、事实ID、竞品ID/原点序号/片段、关键词与场景词根、排除内容。不能只统计主题频次就跳到写稿。

跨竞品合并同义主题：包装、尺寸、珠径、各卷长度、尺寸选择统一归规格组，不能拆成多个五点。一个竞品原点含多个主题时先拆解；不同竞品重复提到同一卖点时先合并，再决定本品点位。比较全部五点，不仅第三与第四点。

场景词根也参与选题。用户已允许的常规场景可结合词库“属性”形成婚礼、圣诞树、DIY等不同主题，分别记录使用语境和可解释的利益。它们不是只供第五点罗列的装饰词，也不需要仅因产品表未逐词重复而再次确认。引用竞品场景不连带采用其材料、操作或性能声明。

按 [五点规划](bullet-plan.md) 交接已去重的提纲；详尽规格放不进第一点时交长描述/规格表，不拿第四点补尺寸。

资料不足以支持五个有区分度的重点时，交付可支持的部分及缺口，不凑数。本阶段交付内容规划，不直接交付最终五点文案。

其他品牌与违规词可以保留在内部原文证据中，但不得作为本品可直接使用的措辞。品牌排除名单不得因竞品筛选而缩减；本品品牌不明或词库缺失时，不宣称相关检查通过。最终表达仍需后续写作和复查。

## 输出

输出一份五点竞品分析报告：分析范围及等级分布、卖点主题与频次、表达结构、潜在购买疑问、本品适配矩阵、五点建议重点与顺序、信息缺口。

可复用结论至少记录 insight_id、competitor_ids、source_refs、evidence、observation、inference、fact_ids、adoption_status、reason，target_field 固定为 bullets。频次结论附产品数、分母和等级分布；缺失值明确为空，不补造 ID。

分析默认使用用户当前语言，原文证据保留来源语言。中间数据沿用 `work/amazon-listing/<project-id>/`，交付文件存当前工作区 `outputs/`。资料更新后复核受影响结论。

交付前检查来源可追溯、重复未放大统计、推断未冒充真实反馈、建议有本品依据及未决事项明确。本模块不声称已完成成稿合规复查。
