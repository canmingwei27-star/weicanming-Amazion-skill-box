# 关键词规划

输出可供标题、五点、长描述、ST 写作使用的关键词分配表。每项采用决定同时考虑本品事实、用户相关性标签和品牌/违规词排除规则；不以埋词数量替代内容准确性。

## 输入与事实判断

读取资料接收结果中的 project、keywords、roots、product_data / facts、brand_rules、forbidden_terms、sources 和未决问题。原表来源为：关键词表“关键词”“相关性”“月搜索量”；词根表（示例 Unique Words）“词语”“关键词性”“属性”。必要时读取竞品分析结论，但竞品词语不自动成为有搜索量依据的关键词。

产品信息表中明确、适用于本次变体且无冲突的数据可以直接使用，无需反复确认。参考资料中的新增功能、规格、适用对象或性能声明需询问用户是否适用于本品；确认前不据此放行发布字段关键词。QA人工筛选候选可用这些来源拟题拟答，逐条标记未确认，不自动放行其他字段。语言和结构参考本身不需要逐项确认。

逐词判断产品类型、功能、属性、使用对象与场景是否由本品事实支持。原标签与事实不符时保留原标签并标记冲突，不为保留高搜索量词而改写本品事实。相关性待定的词进入待确认清单，继续处理其余词。

## 排序与筛选

标签顺序固定为：绝对精准 ＞ 相对精准 ＞ 一般相关 ＞ 泛相关 ＞ 不相关 ＞ 未收录。关键词的标签取“相关性”，词根的标签取“关键词性”。

- 先判断能否使用，再在可用候选中按标签排序；原关键词同级按有效月搜索量降序，缺失搜索量排在同级有数据项之后，相同时保留来源顺序。
- 月搜索量不能跨相关性等级提升排名。不同站点、时间范围的数据分开比较；空白不是零。
- 词根未提供独立搜索量时不估算、不继承整句关键词搜索量。词根同级结合“属性”、事实与目标字段选用，不凭空生成搜索量排序。
- 不相关词排除；未收录词不等于无关或零搜索量，保留标签，在事实相关、无禁用冲突且确有表达价值时才作为低优先级补充。用户的排序不意味着必须使用六个等级。
- 泛相关词只用于本品真实适用的场景或对象。未知标签、空白标签及冲突记录单列，不自动映射为未收录。
- 排除其他品牌、违规词和不符合本品事实的词，包括包含禁用品牌/词语的完整短语。不得通过拆词、连字符、拼写变体绕过禁用。

保存被排除的原词、等级、来源与具体原因，不从原始词库删除记录。

## 词根组词

将“词语”作为组词素材，以“关键词性”确定优先级，以“属性”理解它属于何种产品、特征、场景或人群信息；属性未标明时不擅自补成已确认分类。

主标题、五点、长描述和QA按目标语言正常语法和搭配组合；副标题采用适用词根堆积，不要求完整句子或连贯短语。所有字段均不得拼凑互相矛盾的属性。五点、长描述和QA可使用必要语法连接词；主副标题适用更严格的 [标题规则](title-plan.md)：除主标题品牌、数量、总长度、颜色外，全部取词根库，连接词和词形也必须有原始词根来源。

每个组合记录 component_root_ids、组词理由、关联 fact_ids、目标字段。词形变化要单独标注，不伪称原词精确命中。组合未在原关键词表出现时标为 generated_combination，搜索量为 null；若确实命中原表，关联该关键词 ID 和其真实指标，不能累加词根或其他短语的搜索量。

## 分配到字段

| 字段 | 核心任务与分配规则 |
| --- | --- |
| 主标题 | 固定品牌→数量→总长度→颜色→精准关键词，再按原等级补充库内词根至75字符含空格；固定前缀之外不添加库外词 |
| 副标题 / Item Highlights | 全部从词根库选取适用词根并堆积，按原精准等级优先增加覆盖；严格111–124字符含空格，单空格连接，禁标点及符号；不要求连贯短语，不添加库外连接词或性能句 |
| 五点 1 | 对应已确定的包装/规格主题，集中分配数量、总量、尺寸词；详尽参数溢出到长描述/规格表，不另占一点 |
| 五点 2 | 问题、可证实功能与客户利益相关词 |
| 五点 3–4 | 先依据竞品主题与词根属性明确两个不同主题，再分配核心、用途、场景或人群词；常规适用场景可独立成点 |
| 五点 5 | 承担尚未覆盖的用途、人群或操作主题；场景词不限于此点，不能把全部场景堆成清单 |
| 长描述 | 尽可能覆盖绝对精准、相对精准、一般相关、泛相关中适用且无禁用冲突的词根；允许与标题、五点重复，采用回答问题和解释利益的逻辑 |
| ST | 先全量纳入绝对精准候选，按绝对精准＞相对精准＞一般相关＞泛相关＞不相关＞未收录排列；所有等级对照当前标题、副标题、五点、长描述、QA及ST去重。单空格连接，目标约240、最多250字符含空格；最终由ST模块生成 |

核心词与补充词依据产品识别价值、相关性和字段用途区分，不强制每词只分配一次，也不要求所有字段重复所有词。ST 此处只交付候选及优先级，不冒充已完成最终ST生成与校验。

标题的主副两段合计，同一词库词根最多出现两次，优先避免重复；长描述不沿用这个重复上限。完整短语嵌入与词根分散覆盖分别规划，不承诺同等搜索效果。

## 五点场景词分配

先按词根属性整理场景、人群、用途候选，再参与五点主题划分。优先使用用户标注的精准词与适用场景，不将“只写产品表已逐词列出的场景”作为门槛。以婚礼、圣诞树、DIY等不同语境形成有区分度的点，或作为对应主题的例子；只有原库实际存在的词才记录root_id。每点保存原等级、来源、计划语境及实际覆盖。主张与参数不重复，关键词可按表达需要重复。

## 输出与覆盖交接

每条记录包含 keyword_id / root_id、原词、类型、原标签、优先级、原搜索量及来源、属性、事实依据、采用状态、核心/补充角色、目标字段/点位、组词方式及原因。附待确认问题、禁用/不相关排除清单和可用但未分配的词及原因。

分配表属于计划，不将“计划使用”记为“实际覆盖”。后续成稿检查时，分别统计精确覆盖、词形变化、仅语义覆盖和未覆盖，并列出各字段位置。总词库分母和适用词分母均保留，不通过删除未覆盖词提高覆盖率。不得宣称覆盖率等于平台收录或推荐概率。

输出使用用户当前语言，词语保留原文。沿用项目 work 目录存中间数据，需要文件交付时放 outputs。品牌、禁词或本品事实更新后重新核对受影响的分配。

如需核对后续五点、标题及 QA 的字符数，可使用 [计数工具说明](copy-check.md) 和 `../scripts/check_copy.py`。工具只验证指定的机械约束，不代替事实、品牌、禁词或平台规则审查。
