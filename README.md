# Amazon Review Analysis

> 一个可复用的 AI Skill：把 Amazon 买家评论按频次和严重性拆解成产品优劣势，并输出有评论依据的选品与运营建议。

适用于 US marketplace 产品研究场景——无论是直接粘贴评论表、上传评论文件，还是只需要一份可复用的分析 Prompt。

---

## 它能做什么

- **直接分析评论数据**：给评论区或评论文件，产出结构化的优缺点报告。
- **生成可复用 Prompt**：只要模板不要结果时，输出一份复制即用、可自己改的分析提示词。
- **两者都给时**：以评论数据为准做分析，只有你明确要求时才附带 Prompt。

它不会编造评论结论：评论不支持的市场规模、竞品对比、买家画像等内容，一律标注为 unknown 或需要更多证据。

---

## 主要特性

| 特性 | 说明 |
| --- | --- |
| 按 ASIN 分组 | 每个 ASIN 独立统计、独立分母，不做跨 ASIN 合并计数 |
| 频次 × 严重性分离 | 出现得多不等于问题严重，两者分别评估 |
| 主客观分离 | 区分已观察到的缺陷与主观偏好，区分孤例与复现模式 |
| 评论外的反馈单列 | 物流、卖家、客服问题与产品反馈分开呈现 |
| 小样本自觉 | 样本量小的时候明确提示"一两行就能大幅改变占比" |
| 不臆测星级 | 没有评分字段就不推断评分分布，情感只从评论文本得出 |

## 输入格式

默认三列表格，每行一条评论：

| ASIN | 标题 | 内容 |
| --- | --- | --- |
| B0... | Review title | Review text |

- `标题` = 买家评论标题，`内容` = 评论正文；标题只补充上下文，不单独算一条评论。
- 列名等价即映射（按语义匹配即可）。
- Excel 文件遵循命名约定：`{ASIN}-US-Reviews-{YYYYMMDD}.xlsx`
  - 例：`B0DB88Q37D-US-Reviews-20261016.xlsx`
  - 文件名日期是**数据导出日期**，不是单条评论的日期。
  - 文件名 ASIN 与表格 `ASIN` 列冲突时：标出不一致，并按 `ASIN` 列分别计数——不静默改写行。
  - 日期或其他文件名字段缺失/格式异常：报为 unavailable，不猜测。

## 分析规则（核心方法）

1. **建立每个 ASIN 的数据集**：统计数据行、可用字段，标记缺失或疑似重复记录；没有 review ID 时，重复行只标记、不擅自删除。
2. **确定可用分母**：空白或不可用的评论正文从该 ASIN 的可分析样本中剔除，并说明剔除了多少、为什么。
3. **按语义合并主题**：等价反馈合并为一个主题；每条评论行对同一主题最多计一次，一行可同时计入多个不同主题。
4. **按维度归类**：如质量/耐用性、功能/性能、材质/做工、尺寸/适配/兼容、安装/使用、设计、包装/配件、性价比、物流/卖家支持；评论支持的其它维度可新增。
5. **频次分级**（必须同时给出原始条数与占比）：

   | 频次 | mention rate |
   | --- | --- |
   | high | ≥ 20% |
   | medium | 5% – < 20% |
   | low | < 5% |

   其中 `mention rate = 提及该主题的评论行数 / 该 ASIN 的可分析评论行数`。一个主题横跨多个维度时占比之和不必等于 100%。
6. **严重性分级**（high / medium / low）：依据对功能、安全、易用性或退货意愿的实际影响，并给出证据；没有评论支持时不推断安全隐患。
7. **示例与引用**：可以使用简短改述，但改述绝不标为原话；引用原文时保留原始措辞，并隐去评论者个人信息。

## 输出结构

按 ASIN 分别输出，固定六节：

1. **总体结论** — 供给/可分析评论数、整体模式、主要优点、核心缺点、数据限制。
2. **优点分析** — 频次、维度/主题、评论行数、mention rate、证据摘要、产品/Listing 启示。
3. **缺点分析** — 频次、维度/主题、评论行数、mention rate、严重性、证据摘要、有依据的改进建议。
4. **优先改进项** — 频次与严重性合起来排序；不把孤例描述成普遍问题。
5. **产品开发与运营建议** — 分必要修复项 / 可选增强项 / 有证据支撑的卖点；产品反馈与物流、卖家服务反馈分开。
6. **分析限制** — 小样本、缺失的评分/日期/变体字段、可能的重复行，以及本数据无法支撑的结论。

某个维度证据不足时，直接说明证据不足，而不是用假设把表格填满。

## 内置的可复用 Prompt

要求只产出 Prompt 时，生成一份可搭配"粘贴表格或上传文件"使用的提示词，要求下游 AI：

- 逐个 ASIN 单独分析，分母专属该 ASIN；
- 每行数据 = 一条评论，同一主题每行最多计一次；
- 合并等价反馈，并报告行数、分母与 mention rate；
- 套用上面的 high/medium/low 频次区间，并对小样本加注；
- 分开优点、缺点与非产品类问题；
- 区分提及频次与严重性；
- 所有发现与建议都要落在给定的评论上；
- 输出执行摘要、分类优缺点、优先改进项与产品开发机会。

Prompt 保持易复制、易修改；不写死没有依据的产品结论，也不指示模型去抓取 Amazon 或访问用户未提供的评论。

## 使用方式

1. 把本文件保存为 `SKILL.md`，放进你的 AI 助手的 skill / 指令目录（例如 `skills/amazon-review-analysis/SKILL.md`，实际路径取决于你用的工具）。
2. 在对话里提供评论表（粘贴或文件），或直接说明"给我一份可复用的分析 Prompt"。
3. 未指定语言时，报告用中文，有价值的顾客原话保留英文。

---

## 分析限制

- 没有评分字段时，不推断评分分布；情感只能从评论文本描述。
- 样本很小时，一两条评论就能显著改变占比，避免给出宽泛结论。
- 缺少评论 ID 时无法确认重复，重复行会被标记而非删除。
- 竞品对比、买家画像、市场结论等评论无法证实的内容，一律标为 unknown / 需要更多证据。
